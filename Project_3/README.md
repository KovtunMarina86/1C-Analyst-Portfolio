# Проект 3: Автоматизация процесса согласования заказов поставщикам

**Компания:** LOOK24/7 (Самарский филиал)  
**Задача:** Настроить многоуровневое согласование заказов поставщикам в 1С:ERP

---

## Описание проекта

Руководитель отдела закупок выдвинул новые требования: нужно настроить процесс согласования заказов поставщикам, в котором будут участвовать руководитель отдела закупок и финансовый контролёр — во всех случаях. Если сумма заказа превышает 100 тысяч рублей, дополнительно будет требоваться согласование директора по закупкам.
