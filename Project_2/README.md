# Проект 2: Работа с типовой функциональностью 1С:ERP

**Компания:** LOOK24/7 (Самарский филиал, производство сумок)  
**Задача:** Проанализировать процесс закупок и определить возможности автоматизации типовыми средствами 1С:ERP

---

## Описание проекта

Компания LOOK24/7 выкупила небольшое производство сумок в Самаре. Необходимо проанализировать документы самарского филиала по закупкам, смоделировать процесс в 1С:ERP и определить, какие требования могут быть реализованы типовыми возможностями системы, а какие требуют доработки.

**Процесс закупок включает:**
1. Ведение справочной информации о товарах, складах, цехах (товаровед)
2. Проведение тендера среди поставщиков (руководитель отдела закупок)
3. Проведение закупок по методике ROP (менеджер по закупкам)
