# Проект 1: Сбор и анализ требований к бизнес-процессу

**Компания:** LOOK24/7  
**Задача:** Формализовать бизнес-процесс производства одежды на заказ

---

##  Описание проекта

Компания LOOK24/7 решила расширить спектр услуг — шить одежду на заказ. 
Необходимо описать бизнес-процесс и составить требования к реализации в 1С:Предприятие.

**Заказчики:**
- Кристина — руководитель отдела корпоративных продаж (РОКП)
- Игорь — руководитель производственного отдела (РПО)
- Алина — руководитель складского хозяйства (РСХ)
