## 🚀 Проекты

### 🔹 Проект 3: Автоматизация процесса согласования заказов поставщикам (1С:ERP)

**Заказчик:** Руководитель отдела закупок (Самарский филиал)

**Задача:**  
Настроить процесс согласования заказов поставщикам с многоуровневой системой утверждения:
- Обязательное согласование с руководителем отдела закупок и финансовым контролёром
- Дополнительное согласование с директором по закупкам при сумме заказа > 100 000 руб.

**Что было сделано:**
- ✅ Смоделирован типовой процесс согласования заказа поставщику (BPMN)
- ✅ Заполнен реестр требований и спроектирован процесс в соответствии с требованиями
- ✅ Составлено ЧТЗ на доработку процесса
- ✅ Разработаны тест-кейсы для проверки доработки
- ✅ Написана инструкция администратора по настройке процесса
- ✅ Описаны процедуры ввода начальных остатков (взаиморасчёты с поставщиками, товары)
